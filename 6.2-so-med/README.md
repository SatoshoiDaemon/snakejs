# Snake — 6.2-so-med

Esta implementação faz parte de um benchmark para comparar o desempenho, a qualidade da entrega e o custo de diferentes agentes ao receberem a mesma tarefa. O identificador desta execução é `6.2-so-med`.

## Como jogar

Abra `index.html` em um navegador. O jogo funciona offline e usa HTML, CSS e JavaScript puros, sem instalação ou etapa de build.

- Clique em **Jogar** ou pressione **Espaço**.
- Use as **setas**, **WASD**, os botões na tela ou deslize no tabuleiro.
- Cada alimento vale um ponto, aumenta o comprimento da cobra e acelera o jogo até um limite.
- A partida termina ao tocar na parede ou no próprio corpo. Preencha o tabuleiro para vencer.
- Pressione **Espaço** ou use o botão da partida para pausar e continuar. O recorde fica no navegador quando o armazenamento local está disponível.
